# Заявки в Google Таблицу (через ссылку, без ключей)

Самый простой способ: Google Apps Script. Внутри твоей таблицы работает мини-скрипт,
который принимает заявку от агента и дописывает строку. Ты даёшь агенту только **ссылку**.

## Шаги

1. Создай таблицу: открой **sheets.new** (войди своей Google-учёткой).
2. В таблице: меню **Расширения → Apps Script**.
3. Удали код по умолчанию, вставь весь файл [`google-apps-script.gs`](./google-apps-script.gs),
   нажми **Сохранить** (дискета).
4. Нажми **Развернуть → Новое развёртывание**.
5. Шестерёнка/тип → **Веб-приложение** (Web app).
6. **Кто имеет доступ** → **Все** (Anyone) → **Развернуть**.
7. **Разреши доступ** своей учёткой (Google предупредит — это нормально, скрипт твой).
8. Скопируй **URL веб-приложения** (заканчивается на `/exec`).
9. Открой файл `tenants/demo/config.json`, впиши URL в поле `lead_webhook_url`:

   ```json
   "lead_webhook_url": "https://script.google.com/macros/s/XXXX/exec",
   ```

10. Перезапусти сервер (`Ctrl+C`, затем снова `python -m uvicorn app.main:app`).

## Что записывается

Когда клиент договорился о просмотре, в таблицу автоматически падает строка:

| Записано | Имя | Телефон | Дата/время просмотра | Объект | ID объекта | Бюджет | Пожелания | Компания | Сессия |
|---|---|---|---|---|---|---|---|---|---|

## Проверка

- Открой URL (`/exec`) в браузере — должно написать «Real Estate AI lead endpoint is running.».
- Доведи диалог с агентом до записи (дай имя + телефон + когда смотреть) —
  строка появится в таблице. Резервная копия всегда пишется в `data/leads.jsonl`.
